# Project 01 - Deploy a Custom Website on AWS EC2 using Nginx

## Objective
Deploy a static website on an AWS EC2 instance using Nginx.

## Business Requirement
The client wanted a simple website that is publicly accessible over the internet.

## AWS Services Used
- Amazon EC2
- Ubuntu
- Security Group
- Key Pair
- Public IP
- Nginx

## Implementation Steps
1. Launched an Ubuntu EC2 instance.
2. Connected using SSH.
3. Updated the server packages.
4. Installed Nginx.
5. Verified the Nginx service.
6. Created a custom `index.html`.
7. Verified the website using the EC2 Public IP.

## Result
The website was successfully deployed and accessed through the EC2 Public IP.
